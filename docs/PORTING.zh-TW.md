# 把這套量測層移植到另一種語言

給想用另一種語言（例如英文）重建這套量測層的人看。**只寫事實，不寫承諾。**
這裡沒有任何一句在說「移植會成功」；寫的是哪些部分與語言無關、哪些不是、
哪些根本不能翻譯。

先讀 [README](../README.md) 的誠實清單。本文件假定你讀過了。

---

## 二、語言綁定、必須重建的部分

逐檔列。每項寫：為何語言綁定、英文對應要解決的語法問題。

### 2a `src/mechanical/lexicon_v2.py` — 全部詞表

**為何語言綁定**：那是一組中文表面形式的閉集。每一條都是只存在於中文的字串。

| 表 | 內容 | 英文版要解決的問題 |
| --- | --- | --- |
| 限制形狀 cue（表五） | 算作「對答案的限制」之證據的表面形式 | 英文標記要求的方式不同——情態動詞（`must`／`should`）、不定詞目的子句、祈使框架裡的裸形容詞。中文字串的 cue 清單在英文裡沒有像，**類別要從英文資料重新推導，不是翻譯**。 |
| 量詞閉集 | 哪些「一＋量詞」是**命名**而非**限制** | **英文沒有分類詞系統，所以這個零件整個不適用。** 英文最近的問題是另一種類型：由 determiner 與量化表達（`a`／`one`／`a couple of`／`a piece of`）承擔，各有自己的形態。移植者要先判斷英文裡是否真有類似的「命名 vs 限制」歧義，**很可能結論是沒有**。 |
| 寫作規格形豁免 | 那些在說「**怎麼處理**材料」、因此永遠不是材料的形式 | 作為類別可部分移轉（`at least N words`、`in the format of`），但表面形式與數字表達的形態不同。 |
| 請託動詞受詞守衛 | 請託動詞帶受詞時，被請託者是誰會被改寫 | 依賴中文語序與特定動詞。英文有自己的樣式（`ask me to` vs `ask me about`），那是**另一個**區分，不是這個的翻譯。 |

### 2b `src/mechanical/clause_v2.py` 與 `src/tools/split_sentences.py` — 斷句與標點

**為何語言綁定**：切分器的規則是一個關於中文標點的決定。全形 `？` 與 `！`
**不是**切點、半形 `?` `!` 是、孤立標點併入前句、換行切段並丟棄。
那套規則是從某一卷的人工切分 gold 反推出來的，不是挑的。

**英文版要解決的**：英文沒有全形／半形之分，所以產生那條規則的前提不存在。
換來的是縮寫句點（`Dr.`、`e.g.`）、小數點、以及與句界互動的引號——
那是這支切分器**沒有**的問題。子句切分同樣依賴中文逗號的用法。

### 2c `src/mechanical/rules_v2.py` — 依賴中文語法的規則

| 規則 | 為何語言綁定 |
| --- | --- |
| 零代詞／主語省略 | 中文話題優先，零主語由話題鏈許可。英文省略主語的環境窄得多，所以建立在「找不到人稱標記」上的偵測器行為不同。另註：本專案自己的實作曾把**零主語**與**非人主語**混為一談，後來才修掉——移植者會以自己的形狀遇到同一個陷阱。 |
| 祈使隱含第二人稱 | 中文祈使句典型無主語，「你」是語用補上的。英文祈使句也無主語，但形態與競爭讀法（不定詞、假設語氣）不同。 |
| 「一＋分類詞」落任務本體 | **不適用**：沒有分類詞系統（見 2a）。 |

### 2d 模型層的 3B adapter

**不可用。** 它是以中文 gold 訓練的。移植需要自己的 adapter（以目標語言的 gold
訓練），或者放棄 adapter 這一票、從替代物重新推導濾網。

一併注意對效能數字的連帶影響：早停條件**只在 adapter 答「無」時**省，
所以報告裡的成本輪廓是那個 adapter 在那個語料上的性質，不會跟著移植過去。

## 三、必須重新簽核、不能直譯的部分

**判準表不能翻譯。** 七標籤定義與 A1～C4 規則是關於某一種語言語法的決定；
把它們寫成英文只會得到一些**看起來像規則、卻沒有對任何東西驗證過**的句子。

目標語言上該走的順序：

1. 先在目標語言上建一小份人工標註集。
2. 重跑一次**規則對齊審計**：把每一條規則的文字與實際實作的碼逐條對帳。
   （本專案做這件事時，審計查出七處偏離，全部屬實。）
3. 由人簽核產出的表。**到這一步之後它們才算判準。**

**gold 標註判例集也要重建。** 那是對歧義個案逐次裁定的累積紀錄，
而那些裁定是關於原語言的。

## 四、最小可比移植

一個移植從哪一步起算與本工作可比：

- **同一套協定**（三方分權、seed 規矩、gold 凍結、守側哨兵）；
- **同樣三個出口**，且 ASK 上限事先講定；
- 目標語言**自己的** T1 詞表，重新推導並簽核（§二、§三）；
- 目標語言的**裸大模型對照臂**，跑同一批卷，且**不與系統臂並行**；
- 勝負判準事先固定：**差值**的 bootstrap 95% 區間必須不含零。

**這樣一個移植跑出的數字，不能與本報告的中文數字直接比較。**
語料不同、正類比例不同、模型對不同。可比的是協定與差異的方向，不是 F1。

## 五、會跟著你走的已知天花板

這些不是中文的性質，任何語言都會出現。

1. **無字面形狀的語義限制。** 要求換個說法、要求更真誠、要求用更高階的詞彙、
   要求更簡單、更短、或要求突出某個重點。本工作某一卷的漏抓**全部**屬這一類，
   而裸模型對照臂漏掉同一群。**詞表再怎麼做也碰不到沒有表面形式的限制**
   ——詞表比對的就是表面。
2. **正類稀疏會讓 F1 變成雜訊很大的量尺。** 正類比例約 10% 時，
   「全判有」基線與兩臂只差幾分。低於某個幅度，這把尺分不出改善與雜訊，
   而那個幅度比好幾次個別改動的效果還大。
3. **早停只在「無」那一支省。** 停止條件在出現否定答案時觸發，
   所以「有」那一群的成本不受它約束。語料變難時那一群變大、延遲輪廓惡化
   ——那是停止規則的性質，不是語言的。
